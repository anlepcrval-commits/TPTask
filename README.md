# C# Practical Tasks Console Solution (Task Project)

Консольное приложение на C# (.NET Framework 4.7.2), представляющее собой интерактивный сборник практических заданий разного уровня сложности с удобно организованным меню навигации.

---

##  Структура проекта

* **`Program.cs`** — точка входа в приложение; запускает главное меню.
* **`MenuRunner.cs`** — отвечает за отображение меню, обработку выбора пользователя и навигацию между уровнями и заданиями.
* **`Task1.cs`** — содержит реализацию базовых практических заданий (Задания 1–14).
* **`Avg.cs`** *(расширяемый класс)* — содержит реализацию продвинутых заданий (Задания 16–34).
* **`Task.slnx` / `Task.csproj`** — файлы решения и конфигурации проекта C#.

## Запуск и сборка

1. Откройте файл решения `Task.slnx` в **Visual Studio 2022 / 2019**.
2. Убедитесь, что выбран целевой фреймворк **.NET Framework 4.7.2**.
3. Соберите и запустите проект (`F5` или `Ctrl + F5`).
4. Следуйте инструкциям меню в консольном окне.
